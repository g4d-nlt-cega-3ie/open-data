Contributing to Geo4Dev Open Data
Thanks for helping grow the open library! All contributions go through issues or pull
requests — the `main` branch is protected and no one pushes to it directly.
Add a publication or dataset
Option A — Submission issue (no Git required)
Go to Issues → New issue → "Dataset / publication submission".
Fill in the title, link, content type, and any location/tags you know.
Submit. A maintainer will review and add it to the catalog.
Option B — Pull request
Fork this repository and create a branch.
Add your record to the catalog data following the field table below.
Open a pull request describing the addition and its source.
A maintainer reviews for completeness, attribution, and fit, then merges.
Improve the website
Code, bug fixes, and new functionality belong in the site repository:
https://github.com/g4d-nlt-cega-3ie/geo4dev-site — fork, change, open a PR.
Data fields
Field	Required	Notes
`title`	yes	Resource title
`description`	recommended	1–3 sentence summary
`content_type`	yes	Publication, Dataset, Training Material, Book, Document
`category` / `subcategory`	recommended	Use existing taxonomy where possible
`author` / `publishing_org`	recommended	Attribution
`country` / `region_city`	optional	Geographic scope
`lat` / `lng`	optional	Enables the map
`tags`	optional	Keywords
`stable_link` / `source_url`	yes	Public, durable link
`license`	recommended	Original license of the resource
Ground rules
Only submit material you have the right to share and link.
Preserve original licensing and attribution.
Be respectful and constructive (see `CODE_OF_CONDUCT.md`).
