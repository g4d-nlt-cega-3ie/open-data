Geo4Dev — Open Data
The community contribution hub for Geo4Dev, an open-science
library of geospatial datasets, publications, and training resources for development and
impact evaluation.
🌍 Website: https://geo4dev.nltgis.ai · 📚 Library · 🗺️ Map · ➕ How to contribute
This repository is where the research community proposes new entries, improves existing
records, and discusses the platform. Everything here is public, reviewable, and
version-controlled.
---
Who runs Geo4Dev
A collaboration of three organizations working at the intersection of geospatial science and
global development:
New Light Technologies (NLT) — builds and maintains the platform.
Center for Effective Global Action (CEGA) — UC Berkeley research network on global poverty and development.
International Initiative for Impact Evaluation (3ie) — evidence-informed development and the Development Evidence Portal.

How to contribute
> All changes are made through **issues and pull requests** — the `main` branch is protected,
> so no one (including maintainers) pushes directly. This keeps the catalog reviewable.
Add a publication or dataset — pick the easiest path:
Open a submission issue — use the Dataset / publication submission issue template and
fill in the link and core details. A maintainer adds it for you. (Easiest — no Git needed.)
Register & submit — for new or unpublished material, go through a short review so the
entry is described consistently.
Open a pull request — fork the repo, add your record, and open a PR for review.
Improve the platform: code and new functionality go to the site repo —
https://github.com/g4d-nlt-cega-3ie/geo4dev-site
Discuss & review: use Discussions for ideas, questions, and reviewing
submissions.
See CONTRIBUTING.md for full details and the data format.
---
Catalog data format
Each entry is a structured record. Fill in as much as you can; coordinates are optional but let
your contribution appear on the map.
Field	Description
`title`	Resource title
`description`	Short summary
`content_type`	Publication, Dataset, Training Material, etc.
`category` / `subcategory`	Topic taxonomy
`author` / `publishing_org`	Attribution
`country` / `region_city`	Geographic scope
`lat` / `lng`	Coordinates (optional)
`tags`	Keywords
`stable_link` / `source_url`	Where the resource lives
`license`	Usage terms
---
Review & publication
You open an issue or pull request.
A maintainer reviews for completeness, attribution, and fit.
On merge it is published to the live library, usually within one release cycle.
See release notes.
Community standards
Please be respectful and constructive (see `CODE_OF_CONDUCT.md`). By contributing a record you
confirm you have the right to share the information and link provided.
Licensing & attribution
Datasets and publications remain under their respective original licenses — always check
and preserve the source license and attribution.
